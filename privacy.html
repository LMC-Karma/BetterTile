Privacy

Last updated 2026-11-28.

BetterTile is an open-source project, LMC‑Karma/BetterTile on GitHub. No company runs it. Its maintainer is based in the United States. This page covers this website and the official BetterTile app.

The official app is the copy the project publishes on its GitHub releases page, which this site’s Download buttons link to. BetterTile is open source, so anyone may build, change and share their own copy. The project is responsible only for the copies it publishes. A copy from anywhere else may behave differently, and this page does not cover it.

This website

The site sets no cookies and stores nothing in your browser. It has no analytics and loads no scripts, fonts or media from other sites.

GitHub Pages hosts the site. GitHub logs each request, including your IP address, under the GitHub General Privacy Statement. The project gets no visitor logs. GitHub shows it only total counts, such as repository views and release downloads. Links to GitHub lead to GitHub’s own pages, cookies and terms.

The app

Your windows, settings, shortcuts, Saved Layouts and App Groups stay on your Mac. The app has no account, telemetry, analytics or crash upload.

The only request the app makes by itself is the update check. Automatic checks are on by default and run about every 4 hours. Each check asks GitHub for the update feed. The request carries your IP address and the app and Sparkle versions in its User‑Agent, in the form BetterTile/<version> Sparkle/<version>. System profile sending is off, so no Mac model or macOS version is sent. Like any web request, it also carries standard headers, such as your preferred languages. You can turn automatic checks off in Settings. Check for Updates in the menu sends the same request when you choose it. When you choose to install an update, it downloads from the project’s GitHub releases.

Send Feedback opens a GitHub form in your browser, with the app version and build in its title. It submits nothing until you do.

Bug reports

Issues, pull requests and their comments on GitHub are public. Crash reports and logs can contain your Mac user name in file paths, and window titles. Read them and remove what you do not want to share before you attach them. Copy Diagnostics leaves out window titles, app names and your user name.

Children and changes

BetterTile is not aimed at children. The site and the app send no personal information to the project.

If this changes, this page changes first, with a new date above. Its history is public in the website’s commit log.

Contact

For a privacy question or request, use GitHub’s private report form. Only you, the project’s maintainers and anyone they invite to the report can read it. It needs a GitHub account. Please do not put privacy requests in a public issue.
