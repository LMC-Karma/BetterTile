# BetterTile 0.5.0 Beta

- **Tabbed** is now available in the public beta. Group windows into resizable panes, select and reorder tabs, drag tabs between panes, and float windows out of the layout.
- Keyboard and Layout Wheel partition snaps move a whole Tabbed pane with its tabs. Native title-bar snaps move only the dragged window.
- Tabbed uses Bento's layout engine for pane resizing and minimum window sizes. Failed placements restore the previous arrangement, and Undo restores completed layout changes.
- Shared frosted curtains cover inactive tabs. Glass transparency settings apply across tab strips, dividers, the Layout Wheel, and other overlays.
- Smoother drag and resize previews, clearer minimum-size feedback, and more reliable divider handles around overlapping windows and the Dock. New installations use an 8-point divider width.
- Improved window closure detection, frame restoration, and cleanup of window details in diagnostics.

Turn off Stage Manager before using Tabbed. Pane assignments and Undo history
last only for the current app session. Edge splits stop at 12 panes, and
cross-display tab dragging is unavailable. Some window actions require floating
a window first. Applications can refuse requested sizes. If window identity or
stacking cannot be verified, the curtain hides and inactive windows may show.
Broader multi-display, fullscreen, and real-application stacking checks remain
under validation.

Tabbed reuses the existing Accessibility permission and reviewed window
observations. It observes Escape only during tab drags and pane divider
resizes. No new permission, dependency, network endpoint, or tracking is added.
The existing signing identity and Sparkle update mechanism remain in use.

The app remains self-signed and is not notarized. A first installation may
require **Open Anyway** in System Settings → Privacy & Security.

This release advances the internal build from 12 to 13. Sparkle uses that build
number to determine update order.
