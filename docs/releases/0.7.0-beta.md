# BetterTile 0.7.0 Beta

**BetterTile is finally notarized! 🎉**

BetterTile is now signed with an Apple Developer ID and notarized by Apple. No
more **Open Anyway** in System Settings. It opens like any other app you
download, and macOS confirms: "Apple checked it for malicious software and none
was detected."

**One last thing: grant Accessibility again.** The new signature is a new
identity for macOS, so the permission from earlier betas no longer applies.
After the update, BetterTile opens Setup at the Accessibility step:

1. Open System Settings → Privacy & Security → Accessibility (on macOS 27:
   **Device Control and Data Access**).
2. Select the old **BetterTile** entry and remove it with **−**. It can still
   show as on, but it belongs to the old signature.
3. In Setup, select **Request Access…** and turn BetterTile on.

That's it. Future updates keep the permission.

Nothing else changes from 0.6.3. BetterTile still runs only on Apple silicon
Macs and requires macOS 26.
