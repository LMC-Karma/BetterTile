# BetterTile 0.6.3 Beta

- **Choose how windows behave during setup.** Setup now has a Starting Mode
  step: Manual, Adaptive or Tabbed, each with a short clip and a plain
  description. The choice applies when you select Finish. Desktops you have
  not changed switch to it, and you can change any desktop later from the
  menu bar.
- **See what to try first.** The last setup step shows six features with a
  clip and a "Try it now" line each: snapping, linked resizing, the Layout
  Wheel, keyboard shortcuts, Saved Layouts and Repair Layout.
- **Copy Diagnostics.** A new menu item, after Send Feedback…, copies a
  plain-text report for bug reports: versions, displays, desktop modes,
  window counts and settings. It never includes window titles, file names, app
  names or identifiers. Nothing is sent or saved.
- **Clearer Focus mode Restore.** When macOS refuses to bring a window back
  after Restore, or its app is not responding, BetterTile names the app and
  suggests Repair Layout. Repair Layout no longer reports success while that
  window is still hidden.
- **Saved Layout editor.** A save that cannot be written now shows an error
  instead of closing BetterTile.

People who already finished setup do not see it again. Open it from the
menu bar to see the new steps.

BetterTile still runs only on Apple silicon Macs and requires macOS 26.

Turn off Stage Manager before using Tabbed. Pane assignments, remembered
desktops of disconnected displays, followed Saved Layouts and Undo history
last only for the current app session. Cross-display tab dragging remains
unavailable. Applications can refuse requested sizes.

The Sparkle update framework is updated from 2.9.5 to 2.10.1. The update
feed, signing identity and Sparkle update keys do not change. Each release now
also includes a copy of its disk image named `BetterTile.dmg`, so the download
link always points at the latest release. No permission, network endpoint or
tracking is added. Existing beta users do not need a new Accessibility grant
because of this release.

The app remains self-signed and is not notarized. A first installation may
require **Open Anyway** in System Settings → Privacy & Security.

This release advances the internal build from 18 to 19. Sparkle uses that build
number to determine update order.
