# BetterTile 0.4.6 Beta

- Refreshed native menu and Settings, with clearer action icons and reliable drag reordering.
- More reliable Bento layout retention when switching desktops, plus drag snapping on desktops with one window.
- New **New window side** preference in Bento Behavior: Automatic, Left, Right, Top, or Bottom. Existing layouts stay in place.
- Minimized Bento windows return to their prior position even when macOS delivers delayed window observations.
- Improved divider handling and an interactive resize preview, larger corner snap regions, and correct final drag placement.
- Layout Wheel selection matches its visible buttons near screen edges. Opening jitter no longer picks an unintended action.
- Reduced duplicate Wheel updates and improved cleanup when settings change or the app quits.

This remains a public beta. Space-switch stability has been checked on a single display; broader display/fullscreen combinations remain under validation.

The beta keeps the existing signing identity and update mechanism. No additional permissions, dependencies, networking or tracking are introduced. Existing settings and action order are preserved.

The app remains self-signed and is not notarized. A first installation may
require **Open Anyway** in System Settings → Privacy & Security.

This release follows 0.4.51. Its internal build number increases from 11 to 12;
Sparkle uses that build number to determine update order.
