# BetterTile 0.6.0 Beta

- **Saved Layouts.** Save a desktop's arrangement and bring it back with one
  click. Each pane can prefer apps or an **App Group** (a named list of apps);
  while a layout is followed, a new window of a preferred app goes into its
  pane. Bind a Saved Layout to a set of displays and BetterTile applies it
  automatically when those displays connect. Apply never opens an app or
  takes a window from another desktop, and **Undo Apply** puts the windows back.
- **A new Layout Wheel.** Choose the **Grouped** style for groups such as Size,
  Thirds, Displays, Mode and Choose Layout, each with its own fan of commands,
  or keep the **Custom** style with one or two rings. The wheel can now change a
  desktop's mode, choose a Tabbed layout and apply Saved Layouts. It has new
  triggers, sizes and style presets, a liquid-glass look, and its own Settings
  page. In a One Level wheel, the bottom sector is now **Repair Layout**, and
  Repair Layout from the wheel now works in every mode, as it does from the
  menu. Wheels that still use the original assignments change once; your own
  changes stay. To get Bottom Half back, choose it for the bottom sector in
  Settings → Layout Wheel.
- **Tabbed gets more controls.** **Change Layout** shows a picture of each
  layout. New commands select tabs and move them between panes; give them keys
  in Settings → Shortcuts. Tab
  bars can hide until you point at them. The **+** button in a pane opens an
  app straight into it. A floating window can be dragged into a pane as a tab.
  Terminal and other apps that resize in steps now fit their panes, browser
  popups stay open in panes with hidden tabs, and dialogs stay above the layout
  after an app switch.
- **The Dock no longer pushes your layout around.** With auto-hide on,
  BetterTile no longer shrinks the layout when the Dock appears, so no gap is
  left after it hides. Turn on **Leave space for Dock** to keep the Dock's space
  free instead. A Dock moved to the side of a display now makes Tabbed refit, and
  **Repair Layout** no longer rebuilds a gap from a stale Dock size.
- **Multiple displays are more reliable.** **Next Display** and **Previous
  Display** make room on the destination and close the gap on the source. A
  window dragged across the edge between two displays lands where the overlay
  shows.
- **Adaptive recovers by itself.** Adaptive is the new name for Bento, and
  Manual is the new name for Native. When an app stops responding and comes back,
  its windows rejoin the layout. BetterTile stops a placement when you change the
  mode, desktop or work area, and asks for whole-point frames so apps don't
  round windows out of place.
- **Redesigned Settings.** Settings has separate pages, search across every page,
  one app picker everywhere, a Shortcuts page, switches to pause Per-App
  Rules, adjustable Snap Zones, and a **Launch at login** option. The Settings
  window no longer floats above other apps.
- **Dark is the default app icon.** Your icon choice now updates Finder as well
  as the Dock.
- **Smaller fixes.** Minimum sizes are learned only when an app really refuses a
  size. A configuration file that fails to load is kept, not replaced. The menu
  bar panel opens and closes with animation.

**This release runs only on Apple silicon Macs.** Intel Macs stay on 0.5.2
and are not offered this update. BetterTile still requires macOS 26.

Saved Layouts and App Groups are local files in BetterTile's Application
Support folder. They store app bundle IDs and layout shapes, not window titles
or documents. **Launch at login** is off by default and uses the standard macOS
login item; you can also change it in System Settings → General → Login Items.
Choosing Classic or Ice Blue gives the installed app a custom Finder icon;
choosing Dark removes it.

Turn off Stage Manager before using Tabbed. Pane assignments, followed Saved
Layouts and Undo history last only for the current app session. Cross-display
tab dragging remains unavailable. Applications can refuse requested sizes.

No new permission, dependency, network endpoint, or tracking is added. The
existing signing identity and Sparkle update mechanism remain in use. Existing
beta users do not need a new Accessibility grant because of this release.

The app remains self-signed and is not notarized. A first installation may
require **Open Anyway** in System Settings → Privacy & Security.

This release advances the internal build from 15 to 16. Sparkle uses that build
number to determine update order.
