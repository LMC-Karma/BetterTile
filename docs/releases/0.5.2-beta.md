# BetterTile 0.5.2 Beta

- **Popups float.** File pickers, settings and progress dialogs, About windows, and other fixed-size windows now float instead of joining a Bento or Tabbed layout.
- **Bento measures minimum sizes.** It measures each new window's minimum size before placing it, so panes no longer overlap when an application refuses a small size. A new window splits its pane along the longer side. Leaving Tabbed or using Repair Bento leaves no empty slot.
- **Balance on new window.** A new setting in Settings → Window Layout → Bento Behavior gives every pane an equal share when a window opens. It is off by default.
- **Tabbed improvements.**
  - Tabs fit their titles, and switching tabs is faster.
  - Reordering tabs of different widths is steady.
  - Dragging a background tab out keeps the tab its pane was showing.
  - A hidden tab that needs more room grows its pane, and the pane returns to your size when that tab leaves. If the tab cannot fit, the message names the window in its way.
  - A new window that fits no pane floats instead of failing.
- **Faster layouts.** Layouts are written to every application at once. Live Resize stays smooth in browsers. Ghost previews stay until the windows land.
- **A hung application no longer stalls BetterTile.** Its windows are skipped briefly and a message says it is not responding. A keyboard shortcut no longer moves another window while the front application is hung.
- **License information in the app.** Settings → General → License shows BetterTile's license and the third-party notices, which now ship inside the app.
- **Restoring windows is more reliable.** A minimized window that returns keeps your later layout changes and native edge resizes. Focus mode restores peers that closed or lost membership.

Measuring a minimum size briefly asks the new window for a very small size and
puts it back at once; some applications show this as a short flash. Minimum
sizes stay in memory only and are forgotten when an application quits.

Turn off Stage Manager before using Tabbed. Pane assignments and Undo history
last only for the current app session. Cross-display tab dragging remains
unavailable. Applications can refuse requested sizes. Multi-display and
Space-switch behavior remain under validation.

The popup rules are adapted from AeroSpace (MIT License); see
THIRD_PARTY_NOTICES.md. No new permission, dependency, network endpoint, or
tracking is added. The existing signing identity and Sparkle update mechanism
remain in use. Existing beta users do not need a new Accessibility grant
because of this release.

The app remains self-signed and is not notarized. A first installation may
require **Open Anyway** in System Settings → Privacy & Security.

This release advances the internal build from 14 to 15. Sparkle uses that build
number to determine update order.
