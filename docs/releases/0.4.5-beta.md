# BetterTile 0.4.5 Beta

BetterTile 0.4.5 adds the Layout Wheel for fast, pointer-centered window
placement. Hold the configured modifier trigger, move to an action sector, and
release to apply it. The wheel supports one or two levels, configurable
actions, cancellation from its center or empty sectors, and Repair Bento when
the display is using Bento mode.

An optional Middle Click trigger provides one-handed activation. When enabled,
BetterTile reserves unmodified middle-click system-wide while the feature is
active; modified middle-clicks and other buttons continue to pass through.
The feature is disabled by default and does not request Input Monitoring.

Update checks now run every four hours by default while BetterTile is running.
They remain disableable in General Settings, and update archives continue to be
authenticated by Sparkle.

This beta uses the stable BetterTile Beta signing identity introduced in 0.4.1,
so an existing Accessibility grant should continue across updates. The app is
still self-signed and not notarized; first launch may require **Open Anyway**
in System Settings → Privacy & Security.
