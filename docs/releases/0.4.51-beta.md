# BetterTile 0.4.51 Beta

BetterTile 0.4.51 improves Repair Bento. Repair now chooses the valid layout
that keeps windows closest to their current positions, so a window on the
right or bottom stays on that side when possible. Three- and five-window
layouts can also mirror their larger pane to match the existing arrangement.

Clicking BetterTile's Dock icon while the app is already running now opens or
raises Settings. The Dock menu also includes **Open Settings…**. An ordinary
cold launch remains unchanged.

This release does not change BetterTile's permissions, privacy behavior,
update feed, or data handling. It continues to use the stable BetterTile Beta
signing identity introduced in 0.4.1. The app remains self-signed and is not
notarized, so first launch may require **Open Anyway** in System Settings →
Privacy & Security.
