# BetterTile 0.5.1 Beta

- More reliable Tabbed moves and selections during rapid interaction. Queued moves stay in order, and clicks made while a placement finishes select the intended window.
- Native title-bar drops update pane membership and Undo only after placement succeeds. Cancelled or refused placements restore the previous tabs and selection.
- Reduced redundant overlay updates and window raises in Tabbed. Synthetic measurements show lower overlay refresh cost; real-app performance depends on the application and desktop.
- Choose **Classic**, **Ice Blue**, or **Dark** in Settings → General → Appearance. The choice is saved across launches. Turn on **Show Dock icon** to see it; Finder and the installed app keep Classic.
- Refreshed app icon artwork and clearer Dock icon visibility guidance.

Turn off Stage Manager before using Tabbed. Pane assignments and Undo history
last only for the current app session. Cross-display tab dragging remains
unavailable. Applications can refuse requested sizes. Broader real-app stacking,
multi-display, and Space-switch behavior remain under validation.

The icon choice is stored locally. No new permission, dependency, network
endpoint, or tracking is added. The existing signing identity and Sparkle update
mechanism remain in use. Existing beta users do not need a new Accessibility
grant because of this release.

The app remains self-signed and is not notarized. A first installation may
require **Open Anyway** in System Settings → Privacy & Security.

This release advances the internal build from 13 to 14. Sparkle uses that build
number to determine update order.
