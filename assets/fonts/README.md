# Font provenance

Inter and Instrument Serif are unmodified fonts from google/fonts at commit
`0b58fb370093f9a9f4ff785d94405710b79de67c`.

- Inter: `ofl/inter/Inter[opsz,wght].ttf`.
  License: Inter-OFL.txt, SIL Open Font License 1.1.
- Instrument Serif Italic: `ofl/instrumentserif/InstrumentSerif-Italic.ttf`.
  License: InstrumentSerif-OFL.txt, SIL Open Font License 1.1.

Source: https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl

The site serves Latin WOFF2 subsets with font-display: swap. They come from the
official Google Fonts stylesheet, fetched on 2026-10-03:

- Inter-latin.woff2 (variable, 48,256 bytes):
  https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- InstrumentSerif-Italic-latin.woff2:
  https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zAjjH7M.woff2

Both keep their OFL 1.1 licenses in this folder. The original TTF files are not
published here; download them from the google/fonts commit above. No Google
Fonts request occurs when a visitor loads the website.
