# Font provenance

Unmodified fonts from google/fonts at commit
`0b58fb370093f9a9f4ff785d94405710b79de67c`.

- Inter-variable.ttf: `ofl/inter/Inter[opsz,wght].ttf`.
  License: Inter-OFL.txt, SIL Open Font License 1.1.
- InstrumentSerif-Italic.ttf: `ofl/instrumentserif/InstrumentSerif-Italic.ttf`.
  License: InstrumentSerif-OFL.txt, SIL Open Font License 1.1.

Source: https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl

These font files retain their own licenses. They are served locally with
font-display: swap. Inter is used for marketing headlines; Instrument Serif
Italic is used for selected headline words. Settings uses the system font.
