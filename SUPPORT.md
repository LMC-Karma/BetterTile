# Support

BetterTile is a free project maintained by volunteers. Use this page to find the
fastest way to get help.

## Get help

1. Read the [FAQ in the README](README.md#faq). It covers first launch,
   Accessibility permission, checking a download, uninstalling, and where
   BetterTile stores settings.
2. Read the [website](https://lmc-karma.github.io/BetterTile/) for feature
   demonstrations.
3. Read the [latest release notes](docs/releases/) and the **Known limits**
   section of the README. Your problem may be a known limit.
4. Search the [open and closed issues](https://github.com/LMC-Karma/BetterTile/issues?q=is%3Aissue).
5. If you find no answer, [open an issue](https://github.com/LMC-Karma/BetterTile/issues/new/choose).
   GitHub Discussions are off, so questions, bug reports, and feature requests
   all go to Issues.

## Report a bug

Use the **Bug report** form. A report that someone else can reproduce is the one
that gets fixed. Include:

- Your BetterTile version and macOS version.
- Your layout mode for the affected desktop: Manual, Adaptive, or Tabbed.
- What you did, what you expected, and what happened instead.
- The apps involved, if you are willing to name them. App names help
  reproduce a problem and are optional.
- Your display setup and whether Stage Manager is on.
- Whether BetterTile has Accessibility permission.
- A crash report, if BetterTile crashed. macOS saves it as
  `BetterTile-*.ips` in `~/Library/Logs/DiagnosticReports`. Remove anything
  you do not want to share before you attach it.

Do not post window titles, documents, or other private content that you do not
want to be public.

## Ask for a feature

Use the **Feature request** form. Describe the workflow or problem first, not
only a proposed control.

## Report a security problem

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).
