Every other way
to place a window.

Drag it to an edge, press a shortcut, or pick it from a wheel. Then bring back a whole desktop in one step.

Drag snapping

Drag a title bar toward an edge or corner. See the placement, then release to snap. Adjust the Snap Zones in Settings.

Keyboard shortcuts and undo

Place windows with global shortcuts, and undo a placement to try another.

Layout Wheel

Hold ⌃ ⌥ ⇧, choose a sector, and release. Escape or the center cancels. Build a Custom wheel with one or two levels.

Grouped Layout Wheel

Choose a group at the pointer, then flick to a command.

Saved Layouts

Save a desktop’s arrangement and apply it later from the menu bar, the Layout Wheel or its own shortcut. Bind a layout to a set of displays, and BetterTile applies it when they connect.

Apply never opens an app or takes a window from another desktop. Undo Apply puts the windows back.

Tabbed

Group windows in resizable panes. Select a tab to bring its window forward. Drag tabs between panes, or drop a floating window into a pane as a tab.

Layout Gallery

Choose a Tabbed layout from a picture of its panes. Every pane keeps its tabs.

Repair Layout

Rebuild a desktop’s layout from its visible windows. Adaptive panes return to equal shares.

Multiple displays

Next Display and Previous Display make room on the destination and close the gap on the source.

Install the beta

The beta is self-signed, without Apple notarization, so macOS asks you to confirm the first launch. It takes one extra step.

  1. Download

    Get the disk image from the latest GitHub release.

  2. Drag to Applications

    Open the disk image and drag BetterTile into your Applications folder.

  3. Open Anyway

    Try to open BetterTile once. Then go to System Settings → Privacy & Security and choose Open Anyway.

Which Macs can run it?

BetterTile needs an Apple silicon Mac with macOS 26 or later.

Why does it need Accessibility?

Accessibility lets BetterTile read window frames, then move and resize eligible windows. The app explains the permission before it asks for it.

Is it really free?

Yes. BetterTile is free forever and open source under GPL v3 or later. There is no paid tier, trial expiry, subscription, advertising, behavioral tracking or sale of user data.

Does the app use the internet?

Window and configuration data stay on your Mac. Update checks and downloads contact GitHub, which receives ordinary connection metadata. Automatic checks run every four hours by default and can be turned off. Send Feedback opens a GitHub form; it submits nothing by itself.

How do updates work?

BetterTile shows the release notes and asks before it downloads or installs anything. Sparkle verifies an EdDSA signature on each update. This is separate from the beta’s self-signed macOS code signature.

What are the current limits?

Turn off Stage Manager before you use Tabbed. Pane assignments, followed Saved Layouts and Undo history last only for the current app session. Tabs cannot yet be dragged between displays. BetterTile does not move windows between macOS desktops. Some apps refuse requested window sizes.

Can I keep using macOS tiling?

Yes. BetterTile works with windows that macOS tiling arranged. For dragging to screen edges, use either BetterTile Drag Snapping or macOS edge tiling, so the two previews do not compete.
