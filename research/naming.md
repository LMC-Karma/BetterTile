# BetterTile naming investigation

Checked **2026-10-03, America/Phoenix**. Some services display 2026-10-04 because their records use UTC. This is a preliminary brand screen, not a trademark opinion or an availability guarantee. Findings describe the public records visible on that date.

## Recommendation

**Keep BetterTile for the website and current product.** Make its distinction come from the shared boundary: adjacent windows resize as one, and the workspace adapts around the work. Develop a recognizable mark and demonstration around that behavior.

BetterTile is easy to pronounce and immediately suggests tiling. It already connects the app, repository, downloads, and documentation. Its weakness is distinctiveness: “Better” is a broad promise, and “Tile” describes a crowded category. The name needs a specific supporting line. Suggested descriptor: **“The Mac window manager that resizes neighbours together.”** This is grounded in the current README, rather than a claim that no competitor can do it. [BetterTile README](https://github.com/LMC-Karma/BetterTile#readme)

The “Better” prefix creates a plausible family resemblance to **BetterTouchTool** and **BetterSnapTool**, both published by folivora. BetterSnapTool directly manages window position and size, while BetterTouchTool spans wider Mac automation and window management. This makes name confusion a credible branding concern. It does **not** establish a legal conflict or imply any relationship between the products. [BetterTouchTool](https://folivora.ai/), [BetterSnapTool](https://folivora.ai/bettersnaptool/)

The three rename finalists below are **explorations for a separate brand preview**, not approved replacement names. None provides enough benefit, with enough certainty, to recommend migration now. Panehaven is the strongest calm, descriptive alternative; Tessune offers more visual flexibility; Tandrow explains shared movement but has the most substantial similar-name concern.

## Evaluation of the current name

| Criterion | Assessment — creative judgment |
| --- | --- |
| Clarity | Strong. “Tile” gives a useful category clue. Pair with “for Mac.” |
| Memorability | Moderate. Familiar components help recall but provide little surprise. |
| Pronunciation and spelling | Strong. **BET-er tyle**; two familiar English words. |
| Searchability | Moderate to weak without “Mac.” Exact-name software reuse exists in a Unity editor tool; ordinary “better tile” searches also have building-material meanings. |
| Visual potential | Strong enough. A shared-boundary symbol can describe the product independently of its initials. The selected identity avoids a three-pane B because Magnet already uses that arrangement. |
| Fit with the experience | Good for snapping and Bento. Less explicit about linked resizing or Tabbed, which the product description and motion must establish. |
| Cost of changing | A rename would add migration work across app identity, documentation, releases, and existing links. No official rename is included in this project. |

The Unity use is an **observed software name conflict**, not a finding of trademark infringement. ## Finalist 1: Panehaven

**Meaning and pronunciation:** PANE-hay-vən. A compound of *pane* and *haven*. This is a proposed brand interpretation, not an assertion that the word is unused.

**Connection:** Emphasizes the intended feeling: an organized desktop that gives attention back to the work. The pane component keeps a useful link to Bento and Tabbed.

**Strengths:** Easy to say; the two parts are familiar; the promise is calm and approachable. “Make room for your work” fits naturally beneath it.

**Weaknesses:** Longer than the best utility names. Spoken aloud, *pane* can sound like *pain*. “Haven” can imply security or storage, which this app does not provide. It is also an existing horror screenplay title, an awkward tonal neighbour for a calm brand.

**Logo direction:** Two panels define a quiet inner space, with the shared boundary forming an abstract H. Avoid a literal house, shield, or cloud-storage box.

**Existing uses and searches:** Exact search found Josef Lemoine’s screenplay **Panehaven** on the author’s own site and the competition organizer’s site. This is **possible confusion / unrelated creative-title use**, not evidence of a competing software product. Searches included `"Panehaven"`, `"Pane Haven"`, and `"Painhaven"` with software/app terms. [Author](https://joseflemoine.com/writing), [Script Pipeline](https://scriptpipeline.com/winner/josef-lemoine)

**Software and GitHub:** Exact-name queries scoped to Apple App Store, Microsoft Store, SourceForge, and Product Hunt found **no relevant result**. GitHub’s public repository-name API returned zero for `panehaven in:name` and `painhaven in:name`. A spaced/hyphenated query returned broad Haven/control-panel matches, not an exact Panehaven app. These are limited screens, not exhaustive native store searches. [GitHub exact query](https://api.github.com/search/repositories?q=panehaven%20in%3Aname)

**Domain/handle:** `panehaven.com` is registered. `.app` RDAP and the exact GitHub user endpoint returned 404. See the evidence table below. Other social handles: **not checked**.

**Preliminary standing:** Best emotional fit of the three, but not enough advantage over BetterTile to justify changing now.

## Finalist 2: Tessune

**Meaning and pronunciation:** tess-OON. A proposed coined blend of *tessellation* and *attune*. It suggests a layout made of fitted parts that adjusts as the work changes. No foreign-language meaning is being claimed.

**Connection:** Supports adaptive Bento and linked movement without restricting the brand to snapping alone.

**Strengths:** Short; visually compact; can carry a distinctive symbol independent of a literal window outline. More flexible than a descriptive pane compound.

**Weaknesses:** Meaning is not immediate. It can be heard or spelled as *Tessun*, *Tessoon*, or *Tessuno*. It resembles the soft invented names used across many software categories. The explanatory descriptor must do more work.

**Logo direction:** A single asymmetric T built from three fitted rectangles. Keep one shared boundary continuous. Avoid decorative tessellation that becomes a generic grid at 16 px.

**Existing uses and searches:** No exact software product was found by the checked web and GitHub queries. The nearby **Tessuno** repository describes agent software; **Tessun Immobilien** is an existing property business. These are **possible confusion**, especially for spoken spelling, not established category conflicts. Search variants included `Tessune`, `Tessun`, and the resulting `Tessuno`. Exact Tessune also appears in non-product online material, so it is not a globally unused word. [Tessuno](https://github.com/sha-shank-03/tessuno), [Tessun Immobilien](https://tessun-immobilien.de/)

**Software and GitHub:** Exact-name Apple App Store, Microsoft Store, SourceForge, and Product Hunt web queries found **no relevant result**. GitHub’s repository-name query returned zero for `tessune in:name`; `tessun in:name` returned the nearby Tessuno project and an unrelated test repository. [Exact query](https://api.github.com/search/repositories?q=tessune%20in%3Aname), [variant query](https://api.github.com/search/repositories?q=tessun%20in%3Aname)

**Domain/handle:** `tessune.com` is registered. `.app` RDAP and the exact GitHub user endpoint returned 404. Other social handles: **not checked**.

**Preliminary standing:** Most flexible visual direction. It trades immediate clarity for a name that would need pronunciation and spelling validation with people.

## Finalist 3: Tandrow

**Meaning and pronunciation:** TAN-droh. A proposed blend of *tandem* and *row*. The rationale is creative; the spelling already appears as a personal name and online handle.

**Connection:** It directly suggests windows moving together. A shared-edge interaction could become both the logo animation and the defining demonstration.

**Strengths:** Two syllables, compact wordmark, active without sounding hurried. Strong relationship to linked resizing.

**Weaknesses:** Near-homophone **Tandro** is already a software name. The exact GitHub and Gitee handles are occupied. Users could omit the final W when searching, and the name does not inherently communicate a Mac utility.

**Logo direction:** A T formed by two neighbouring panels and their continuous shared edge. One panel grows while the other gives it room; the overall frame remains constant.

**Existing uses and searches:** Exact Tandrow returned personal-name and handle uses, including an existing [Gitee profile](https://gitee.com/tandrow) and [GitHub profile](https://github.com/Tandrow). The spelling variant **Tandro** is a meetup-planning app and an anime chat service. Those are **observed software uses** of the variant and **possible confusion** for Tandrow. [Tandro meetup app](https://www.tandro.app/), [Tandro chat](https://www.tandro.de/about)

**Software and GitHub:** The exact-name store/listing web queries found **no relevant product result**. The GitHub name query returned eight results associated with the Tandrow account, including personal test/demo repositories. This is an **observed handle conflict**; no exact Tandrow window manager was found. [GitHub query](https://api.github.com/search/repositories?q=tandrow%20in%3Aname)

**Domain/handle:** `.com` and `.app` registry endpoints returned 404. This does not establish availability. GitHub `Tandrow` exists. Other social handles: **not checked directly**.

**Trademark signal:** USPTO directly shows **TANDRO**, serial **99411231**, as a live pending application owned by Tandro LLC for meeting-planning software in Class 009. Status date shown: 2026-05-05. This is a material **possible confusion** signal for the proposed spelling Tandrow; do not use it as a cleared rename. [USPTO record](https://tmsearch.uspto.gov/search/search-results/99411231)

**Preliminary standing:** The shared-movement rationale is good, but the near-name issue makes this the least advisable finalist. Keep it only as an explicitly labeled exploration.

## Research method and reuse notes

- Source-of-truth product reading: repository `README.md` and `CONTEXT.md`. The name rationale uses linked resizing, Bento, Tabbed, and Layout Wheel as documented concepts. It does not imply cloud sync, artificial intelligence, cross-device input, or Apple affiliation.
- Public web exact-name searches and spelling variants were followed to first-party websites, repositories, store listings, or official records where available.
- Store checks were search-engine queries scoped to `apps.apple.com`, `apps.microsoft.com`, `sourceforge.net`, and `producthunt.com`. They were not exhaustive queries of every national storefront.
- GitHub checks used public `users/{name}` and repository search endpoints. Repository search is substring/token matching, so result counts are screening context, not counts of exact competing brands.
- Domain checks used registry RDAP services for `.com` and `.app`. No WHOIS ownership inference or registrar purchase-availability claim is made.
- Research limitations should travel with any name shown in the brand preview. Do not omit the Tandro application when presenting Tandrow, or turn a zero-result search into an availability badge.
