### Your desktop. Back in one click.

Save a desktop’s arrangement as a Saved Layout. Apply it from the menu bar panel, the Layout Wheel or its own shortcut.
Each pane can prefer apps or an App Group. While a layout is followed, a new window of a preferred app goes into its pane. Bind a layout to a set of displays, and BetterTile applies it when those displays connect.
Apply never opens an app or takes a window from another desktop. Undo Apply puts the windows back. Saved Layouts are local files with app bundle IDs and layout shapes, not window titles or documents.

### Your next move. Within reach.

Open the Layout Wheel: hold ⌃ ⌥ ⇧, choose a sector, and release. Set it up on its own Settings page.
In a One Level wheel, the bottom sector is Repair Layout. Escape or the center cancels. Optional middle click reserves that button system-wide while enabled.

### A few good questions.

#### Still curious?

Read the guide, or ask on GitHub. Feature ideas and bug reports are welcome.
[Read the docs ](https://github.com/LMC-Karma/BetterTile/blob/main/README.md)[Open an issue ](https://github.com/LMC-Karma/BetterTile/issues)

Which Macs can run it?
BetterTile 0.6 requires an Apple silicon Mac with macOS 26 or later. Intel Macs stay on 0.5.2 and are not offered this update. Accessibility is the only macOS permission BetterTile requests. Check the latest release notes before installing a new version.
Why does it need Accessibility?
Accessibility lets BetterTile read window frames, then move and resize eligible windows. The app explains the permission before requesting it.
Is it really free?
Yes. BetterTile is free forever and open source under GPL v3 or later. There is no paid tier, trial expiry, subscription, advertising, behavioral tracking, or sale of user data.
Does the app use the internet?
Window and configuration data stay on your Mac. Update checks and downloads contact GitHub, which receives ordinary connection metadata. Automatic update checks run every four hours by default and can be disabled. Send Feedback opens a GitHub form with the app version and build in its suggested title; it submits no issue automatically. [Security and privacy ](https://github.com/LMC-Karma/BetterTile/blob/main/SECURITY.md)
How do updates work?
BetterTile shows release notes and asks before downloading or installing. Sparkle verifies an EdDSA signature on each update. This is separate from the beta’s self-signed macOS code signature. You can also use Check for Updates from the app.
What are the current limits?
Turn off Stage Manager before using Tabbed. Pane assignments, followed Saved Layouts and Undo history last only for the current app session. Cross-display tab dragging remains unavailable. BetterTile does not move windows between macOS desktops. Some apps refuse requested window sizes. [Full beta limitations ](https://github.com/LMC-Karma/BetterTile/blob/main/docs/releases/0.6.0-beta.md)
Can I keep using macOS tiling?
BetterTile can work with windows arranged by macOS tiling. For dragging to screen edges, use either BetterTile Drag Snapping or macOS edge tiling to avoid competing previews.
